How it works

Three taps. Any device.

Configured for Microsoft Edge on Apple devices. Direct compose uses mailto:; attachment-ready messages use a standard .eml draft because browsers do not allow local attachments to be injected into Mail automatically.

01
Write & attach
Fill recipient, subject and body, then add any audio files. No Google sign-in is required.
02
Open Apple Mail
Tap Open Apple Mail for a normal compose window. Microsoft Edge passes recipient, subject and message through the standard mail link.
03
Styled draft fallback
Need the full styled HTML and attachments together? Download the Apple Mail .eml draft and open it from Files/Finder.

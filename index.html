How it works

Three taps. Any device.

Built for Microsoft Edge on Apple devices as a hosted web app. Normal messages use mailto:; messages with audio use the browser's secure Web Share file handoff to Apple Mail.

01
Write & attach
Fill recipient, subject and body, then add any audio files. No Google sign-in is required.
02
Send to Apple Mail
Tap Send to Apple Mail. If tracks are attached, choose Mail in Apple's share sheet. If there are no tracks, the app opens a normal Mail compose window.
03
Styled draft fallback
Need the full styled HTML and attachments together? Download the Apple Mail .eml draft and open it from Files/Finder.
